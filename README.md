# Protótipo de E-commerce - Materiais Desportivos (Projeto Acadêmico)

Protótipo de site de e-commerce desenvolvido como projeto de faculdade, focado na comercialização de artigos esportivos. O sistema simula a experiência inicial do usuário, contemplando a estruturação de páginas de produtos, além de fluxos de autenticação.

## 🚀 Funcionalidades Atuais
* **Página Inicial:** Vitrine de exibição de materiais esportivos.
* **Autenticação:** Sistema completo de cadastro de novos usuários e tela de login.
* **Navegação Básica:** Visualização de catálogo e detalhes dos produtos.
